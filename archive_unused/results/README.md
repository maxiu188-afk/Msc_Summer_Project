# Archived Results

This directory contains generated outputs that are no longer valid evidence for
the active BioASQ/PubMedQA protocol.

- `local_outputs/`: formerly
  `archehr_sebaseline/outputs/archived_low_usability/`.
- `server_results/`: formerly `server_results/archived_low_usability/`.
- `local_outputs/pubmedqa_question_only_transfer_20260721/`: archived
  question-only PubMedQA run and analysis; the official article evidence was
  omitted, so it is not an active transfer result.
- `local_outputs/bioasq_phase2_elasticnet_even_threshold_diagnostic_20260723/`:
  archived supplemental calculation that binarized the continuous P(True)
  target; it is not the correctness-UQ AUROC used in active results.

The directories were consolidated here on 2026-07-22. Most generated contents
are intentionally ignored by Git; the historical Level-4 pilot snapshot remains
tracked for provenance.
